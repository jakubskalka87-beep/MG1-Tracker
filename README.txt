MG1 Tracker – jednoduchá verze pro iPhone

NAHRÁNÍ NA GITHUB PAGES
1. Rozbal ZIP.
2. Nahraj index.html, manifest.json, service-worker.js a složku icons do kořene repozitáře (stejně jako minule).
3. GitHub > Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Počkej na nasazení. Na iPhonu otevři HTTPS adresu v Safari > Sdílet > Přidat na plochu.

DATA A SYNCHRONIZACE
Tato verze automaticky ukládá data do úložiště aktuálního prohlížeče. Automatická synchronizace mezi různými telefony vyžaduje cloudovou databázi a přihlášení; statický GitHub Pages ji sám neposkytuje. Nezadávej citlivá data. Před přechodem ze starší verze si stará data exportuj, protože toto zjednodušené vydání používá nové datové schéma.
